# Extensão do WinnerZ para o Playnite

Cada jogo aberto pelo [Playnite](https://playnite.link) vira sessão na sua Jornada do WinnerZ, com início e fim exatos.

1. No site, em **Preferências → Pontes → Playnite**, toque em **Gerar a chave e ligar** e copie a chave.
2. Baixe a extensão: https://github.com/winnerzbr/winnerz/releases/download/playnite/WinnerZ.pext e abra o arquivo com o Playnite aberto.
3. No Playnite: menu → Complementos → Configurações de extensões → WinnerZ. Cole a chave e salve.

A extensão é compilada pelo GitHub a cada mudança nesta pasta (`.github/workflows/playnite.yml`).
